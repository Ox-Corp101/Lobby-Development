# Lobby documentation

| Document | What it's for |
|---|---|
| [Product requirements](requirements/product-requirements.md) | The whole product at summary level: what's implemented, approved, proposed, open or future |
| [Open decisions](requirements/open-decisions.md) | Every unresolved decision, with when it's needed |
| [Architecture decision records](decisions/README.md) | Individual technical decisions and their status |
| [Technical principles](technical-principles.md) | The agreed engineering rules for every milestone |
| [Ride discovery, calendar and weather (Revision 6)](plan/ride-discovery-calendar-weather.md) | The detailed ride rules (capacity, private rides, calendar, statuses) |

**Status labels:**
- Requirements use *Implemented*, *Approved*, *Proposed*, *Open* and *Future*.
- Decision records use *Accepted*, *Proposed* and *Deferred*.
- Only an explicit product-owner decision counts as Approved or Accepted.
